======= CONTEXT MENUS ========
- Add music
  ADMIN ONLY: allows to add a new track to the database
- Get rating
  displays the rating of an entry
- Rate
  allows the user to rate the track

========== COMMANDS ==========
WORKS /ping
WORKS /echo <message> <#channel|None>
WORKS /help <command>
WORKS /music-total -> prints the volume of the database
WORKS /music-get-least-rated -> prints the least rated track
WORKS /music-get-rating-of <track_name|None> <artist|None> <sent_by|None> -> prints rating of a track
WORKS /music-unrated-count -> prints the number of unrated tracks by the user
WORKS /music-random-unrated -> prints a random unrated track
WORKS /music-rate-specific <track_name|None> <artist|None> <sent_by|None> -> allows you to rate a specific track
WORKS /test -> test command 

WORKS /music-filter <name|None> <artist|None> <sent_by|None>
WORKS /music-list-top-rated <count|10>
WORKS /music-list-my-top-rated <count|10>
